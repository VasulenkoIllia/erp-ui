# erp-ui: Модулі кіта

Довідка скіла `erp-ui` (що дають модулі A4, A6, B3, N1, N5). Відкривай, коли задача зачіпає тему; правила ядра (`../SKILL.md`) діють і тут.

- **Імпорт і експорт як розділ** (ADR-0050): модуль A4 дає сторінку цілей, майстер на адресі цілі й історію запусків. Свою ціль додавай даними в `targets.add` файла розширення, а не окремою сторінкою; цілі модулів, яких у проекті немає, ховай `targets.hide`. Кнопка на своєму списку веде на `importRunPath(paths, "<ресурс>")`.
- **Довідники** (ADR-0047): модуль A6 дає податки, одиниці, умови оплати, теги й причини. У документі бери значення через `RecordPicker` із `filter={{ active: true }}`, типові — з `dictionary-defaults/current`. Значення не видаляються, лише вимикаються.
- **Пропозиції й замовлення** (ADR-0065, ADR-0067): модуль B3 — список, картка, форма на сторінці й друк пропозиції й замовлення на рушії документа, одні компоненти на описі виду (`sales-kinds.ts`). Клієнти — ресурс проекту (`clients`), товар у рядку — `lineItem`; свої поля, статуси й дії — у `SalesExtension`. «Термін минув» — позначка надісланої, а не статус; надіслану змінюють «Скасувати» й «Виправити». Масово зі списку — «Надіслати», «Скасувати» з причиною й «Видалити» (лише чернетку, як і з картки; надіслану не видаляють, а скасовують, ADR-0066). З прийнятої — «Створити замовлення» (право `quotes:order`): чернетка з тими самими клієнтом і рядками, зв'язок веде сервер; вдруге — неактивне з причиною, пропозицію з нескасованим замовленням не скасовують (`linked`). «Копіювати» — заповнена форма `…/new?copy=<id>`, документ лише після «Зберегти». Потік документів — секція `flow` картки. Замовлення: «Чернетка», «Підтверджено», «Виконано», «Скасовано», «Прострочено» — позначка підтвердженого з минулим «Виконати до»; масово — ще й «Позначити виконаним». Свого розділу пропозицій чи замовлень не пиши: розширення `quotes` і `orders`.
- **Стрічка запису** (ADR-0053, ADR-0054): модуль N1 — сторінка «Мої справи» і слот `aside`: на картці B1 `aside: timelineModule.aside` у розширенні, на своїй Object Page `useRecordSlots({ aside })`. Блок `RecordTimeline` окремо — для інших місць. Без слота запитів до стрічки немає. Без пошти — `card: { messages: false }`, без `GET /me/activities` — `myActivities: false`.
- **Сповіщення** (ADR-0013, ADR-0014, ADR-0046): модуль N5 — сторінки центру й налаштувань; `InboxBell` в оболонці дає дзвіник, лічильник у назві вкладки (`useTabCounter`, `tabCounter={false}` вимикає) і реакцію на push (`usePushSync`). Назву вкладки не збирай із лічильником сам: сторінка ставить назву, хук додає лічильник. Push: контракт `lib/web-push` під `provider.inbox.push`, браузер `lib/push-device`, блок `PushDeviceSection` у формі налаштувань, якщо сервер має канал `push`; дозвіл лише з натискання; фоновий файл `public/erp-ui-push-sw.js` не правимо; на iPhone і iPad push чекає на PWA. У e2e push потрібна повна збірка Chromium (`test.use({ channel: "chromium" })`).
