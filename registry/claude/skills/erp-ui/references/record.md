# erp-ui: Картка запису

Довідка скіла `erp-ui` (шаблон картки, дії запису в палітрі, стрічка запису). Відкривай, коли задача зачіпає тему; правила ядра (`../SKILL.md`) діють і тут.

- **Картка запису** (ADR-0019) — шаблон `ObjectPage` з `templates/object-page`: `back` (посилання до списку зі станом переходу, що повертає фільтри), `header={record && { title, status, fields: [{ id, label, value }], actions: [{ id, node }] }}` (h1 — `RecordHeader`, ціль `headingRef`; без запису `header` не передається — h1 прихований `title`), `statusBar` — `RecordStatusBar` з `erp/record-header`, `sections={[{ id, title, content }]}`, стрічка — `aside` (праворуч чи вкладкою за шириною контейнера). Дані — `useGetOne` з `meta` компанії: шапка одразу з кешу списку, детальний запис (рядки документа) — з `GET /<ресурс>/:id`; помилку запису передавай у `ObjectPage` лише коли запису немає, інакше це стан секції. Фокус після переходу — `useFocusHeadingOnNavigation(heading, location.pathname, ready)` з `hooks/use-focus-heading` (і для списку). Багато розділів — `tabs={{ value, onValueChange }}` (вибрана — в адресі `?tab=` із `replace`, змонтована лише вибрана вкладка, ADR-0024). Своїх розкладок картки, вкладок, смуг етапів і «Назад» через `history.back()` не пиши; у моках — опція `detail` у `createResourceHandlers`.
- **Дії запису в палітрі** (ADR-0044) — картка описує дії даними через `usePaletteActions` з `hooks/use-palette-actions`, а не розбором шапки; дія без права лишається з `deniedReason`.
- **Стрічка запису** (ADR-0053) — `RecordTimeline` з `erp/record-timeline`: нотатки, повідомлення, зміни полів, файли, підписники, заплановані дії на картці. Свою стрічку не пиши. Проект без пошти: `messages={false}`, закритий запис: `readOnly`. Контракт бекенду — шапка `lib/timeline`, адаптер перевизначає `authProvider.timeline`.
- **Видалення й кошик** (ADR-0095) — «Видалити» на картці — `DocumentDeleteAction` з `erp/document-delete-action` (`name` і `texts.trashed` словами модуля): сервер веде кошик для ресурсу — без діалогу, «Перенесено в кошик» зі «Скасувати»; ні — підтвердження з наслідком. Кошик ресурсу — маршрут `<список>/trash` перед `/:id` з `TrashPage` з `templates/trash-page`, кнопка «Кошик» у шапці списку — `TrashLink` з `erp/trash-link`, опис масового видалення — плюс `useTrashKeptFor(resource)` з `hooks/use-trash`. Архів довідника — «Вимкнути», а не кошик. Своїх «Скасувати» після видалення й сторінок кошика не пиши; у моках — `createTrashMocks` з `lib/mock-trash` і опція `trash` ресурсу.
