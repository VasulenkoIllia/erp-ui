# erp-ui: Основа кожного екрана

Довідка скіла `erp-ui` (токени, рух, швидкість, статуси, стани, адаптив, доступність, тексти, числа, іконки). Відкривай, коли задача зачіпає тему; правила ядра (`../SKILL.md`) діють і тут.

- **Лише токени.** Кольори, відступи, радіуси, тіні, шрифти беруться з CSS-змінних тем (`--primary`, `--muted-foreground`, `--success-soft`…). Жодних hex/rgb у компонентах, жодних довільних значень Tailwind на кшталт `text-[#123]`. `dark:` діє лише на екрані й поза `data-theme="light"` (ADR-0082): папір і аркуш друку — як у світлій темі.
- **Рух** (ADR-0009, SPEC §6.6) — лише функціональний (поява, розгортання, підсвітка зміни, прогрес) і лише з токенів: `duration-fast|base|slow`, `ease-standard|enter|exit`. Не `transition-all` і не `duration-200` / `ease-linear` — це ловить `node scripts/erp-ui-check-tokens.mjs`. `prefers-reduced-motion` кіт обробляє сам.
- **Швидкість** (SPEC §18.5): відгук ≤ 200 мс, перший екран ≤ 2,5 с на телефоні (CPU ×4). Сторінки — лінивими чанками (`lazyWithPreload` з `lib/lazy`, не `React.lazy`) у `ErrorBoundary` з `erp/error-boundary`, fallback — `LoadingFallback` з `erp/page-state` (оголошує завантаження скрінрідеру), з попереднім завантаженням при наведенні; важке, що з'являється не одразу, — при відкритті; рядки інших мов — функцією в `createI18n`, перед рендером `await whenI18nReady(i18n)`.
- **Статуси** — бейдж `*-soft` + `*-foreground` + іконка + підпис; ніколи лише колір. Основний колір не використовується для статусів. Статус запису модуля — `StatusBadge` з `erp/status-badge` і тон `StatusTone` (`lib/statuses`): схему й варіанти з урахуванням розширення дають `statusSchema` і `useResolvedStatuses` (ADR-0025).
- **Стани.** Кожен екран із даними має стани SPEC §8.1: скелетон, оновлення, порожньо вперше, нічого не знайдено, помилка з повтором, немає доступу, офлайн, застарілі дані, масова операція, блокування, конфлікт. Порожній стан не підміняє помилку.
- **Адаптив.** Контейнерні запити (`@container`). Таблиця на телефоні → картки; фільтри й піккери → нижня шторка; канбан → одна колонка + «Перемістити в…». Перевір 360, 768 і 1440 px. Текст поля 14 px лише з мишею (`pointer-fine:text-sm`), на дотиковому — 16 px, як у полях кіта (ADR-0096); не `md:text-sm`. Список прапорців із кроком менше 44 px — рядкам `pointer-coarse:min-h-touch`.
- **Доступність.** WCAG 2.2 AA: справжні `button`/`a`/`label`, `aria-label` для кнопок-іконок, альтернатива кожному перетягуванню, цілі ≥ 24 px (≥ 44 px у звичайній щільності), фокус не перекривається.
- **Тексти** лише через i18n (uk + en): рядки проекту — у JSON його просторів імен (тексти сторінки можна винести у свій JSON і підключити `useStrings`), рядки кіта — `useErpUiT()`, а рядки функції кіта, яких немає в базі (`lib/i18n-uk-*`, напр. `roles.*`, `audit.*`), — з її частиною: `useErpUiT(ukRoles)` (ADR-0094); множина `_one/_few/_many/_other` (en — `_one/_other`); без фіксованих ширин для тексту. Мова за замовчуванням — українська. Без довгих тире (— і –): крапка, кома чи двокрапка за змістом; прочерк «—» порожнього значення не текст, він лишається.
- **Числа, суми й дати** — лише `useFormat()` з `@/lib/format`: гроші — мінорні одиниці + код валюти («48 600,00 ₴», інші валюти кодом), кількість і ціна рядка документа — десяткові рядки (`decimal`, `price`, контракт `lib/document-lines`), дати — явні стилі (`date`, `long`, `monthYear`…), календарні дати — рядком `YYYY-MM-DD`. Ніяких `toLocaleString`, `DD.MM.YYYY`, ручних «грн».
- **Іконки** — поняття → іконка лише зі словника `lib/icons` (модулі, статуси, дії); гривня — `HryvniaIcon`; товщину лінії задає `IconProvider`, не пропси окремих іконок.
- **Стани** — `PageState` / `PageSkeleton` з `erp/page-state`; тексти за замовчуванням уже перекладені; стан у секції чи картці — `compact` (рядком, h3), не свій `className`.
