# erp-ui — приватний реєстр UI для ERP/CRM

UI-кіт студії: токени й теми, примітиви на shadcn/ui (Base UI), ERP-компоненти, шаблони сторінок і модулі з контрактами та моками. Нормативний документ — `docs/SPEC.md`.

## Як почати

```sh
pnpm install
pnpm dev          # демо-застосунок
pnpm typecheck && pnpm lint && pnpm test && pnpm e2e
```

Деталі (Playwright, скриншоти, хмарне середовище) — `docs/dev-setup.md`. Порядок робіт — `docs/WAVE-0.md`, зміни — `CHANGELOG.md`.

## Що всередині
| Шлях | Що це |
|---|---|
| `registry.json`, `registry/` | shadcn-реєстр: код елементів і їхній опис (`registry.json` генерується) |
| `docs/CATALOG.md` | каталог усього, що є в кіті (генерується) |
| `docs/using-erp-ui.md` | як підключити кіт у проект і оновлюватися |
| `apps/demo` | демо-застосунок: каталог і перевірка кіта (Vite + React) |
| `docs/SPEC.md` | специфікація: рішення, архітектура, стек, теми, стани, адаптив, доступність, модулі, хвилі, контракти, якість |
| `docs/WAVE-0.md` | бриф першої робочої сесії: кроки, критерії приймання, точки зупинки, ADR |
| `docs/research/` | журнал рішень і два повні дослідження з джерелами |
| `design/` | готові теми (5 палітр × світла/темна), токени, перевірка контрасту |
| `registry/claude/` | блок для CLAUDE.md клієнтських проектів і скіл erp-ui, що ставляться в проекти через реєстр |
