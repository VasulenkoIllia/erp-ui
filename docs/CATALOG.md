# Каталог erp-ui

> Генерується з `registry/registry.config.mjs` скриптом `pnpm registry` — руками не правити.

Елементів: 356. Встановлення в проект: `npx shadcn@latest add VasulenkoIllia/erp-ui/<елемент>` (версія — `#vX.Y.Z`). Як підключити кіт — `docs/using-erp-ui.md`.

Статуси: **draft** — у роботі; **beta** — є в демо й тестах, API може змінитися; **stable** — підтверджено стрес-сторінкою.

## Основа

| Елемент | Назва | Що це | Статус | Демо | SPEC |
|---|---|---|---|---|---|
| `base` | Основа erp-ui | Усе для старту проекту однією командою: теми й токени, базові стилі, cn, вподобання вигляду, мови й форматери, словник іконок, скіл і правила для Claude Code, команда оновлення кіта scripts/erp-ui-kit.mjs. | beta | `appearance` | §3, §6, §19 |
