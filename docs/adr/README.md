| [0073](0073-payments.md) | Оплати клієнтів: проведений документ `sales-payments` на один чи кілька рахунків клієнта, без переплати й авансу (сума кожному не більша за борг, оплата дорівнює рознесенню), «Оплачено» ставить сервер, часткова оплата — сумами на картці, скасування чи сторно, ключ `requestId`, рахунки з боргом рахує сервер | прийнято |
