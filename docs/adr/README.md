| № | Рішення | Статус |
|---|---|---|
| [0001](0001-base-style-nova.md) | Базовий стиль shadcn — Nova | прийнято |
| 0002 | Формат API | крок 0.5 |
| 0003 | Модель входу й контракт профілю | крок 0.5 |
| 0004 | Структура реєстру, назви елементів, доставка в проекти | крок 0.2b |
| 0005 | Підтвердження або зміни стеку | крок 0.6 |
| [0006](0006-external-components.md) | Узгодженість: зовнішні компоненти перебудовуємо | прийнято |
