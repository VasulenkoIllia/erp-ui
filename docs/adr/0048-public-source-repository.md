# 0048. Відкритий код кіта: новий репозиторій, усі права застережено

- Статус: прийнято (змінює ADR-0004, п. 9; SPEC §2 №2, §3.2, §3.3, §19)
- Дата: 31.10.2026
- Хто ухвалив: власник (вікторина 31.10.2026)

## Контекст

Кіт жив у приватному репозиторії, і проекти брали його з токеном. Власник вирішив показати код відкрито.

## Рішення

1. Під адресою `VasulenkoIllia/erp-ui` живе відкритий репозиторій із тими самими тегами.
2. Ліцензія: усі права застережено (`LICENSE`). Код видно, користуватись можна лише з письмового дозволу власника. `package.json` лишається `UNLICENSED`.
3. Чужий код лишається під своїми ліцензіями: `THIRD-PARTY-NOTICES.md`.
4. Внутрішні робочі документи живуть окремо. Для запуску є `docs/development.md`.
5. `docs/SPEC.md` лишається відкритим: проекти отримують його разом із `base` і `claude`, а скіл кіта спирається на його розділи.
6. Доставка: `shadcn add VasulenkoIllia/erp-ui/<елемент>#vX.Y.Z` працює без токена. `node scripts/erp-ui-kit.mjs update` бере архів тегу через `gh api`, тож їй і далі потрібен `gh auth login`, а в CI проекту `GH_TOKEN`.

## Наслідки

- Адреса й назви елементів не змінюються, проекти лишаються на своїх тегах.
- Закріплювати версію можна лише тегом.

## Розглянуті варіанти

- **Відкрита ліцензія (MIT):** відхилено, власник лишає за собою право вирішувати, хто користується кітом.
- **Лишити внутрішні документи відкритими:** відхилено, вони потрібні лише студії.
