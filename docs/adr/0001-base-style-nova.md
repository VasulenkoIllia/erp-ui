# 0001. Базовий стиль shadcn — Nova

- Статус: прийнято
- Дата: 13.10.2026
- Хто ухвалив: власник (за скриншотами порівняння)

## Контекст

shadcn CLI v4 для Base UI має 8 стилів: Vega, Nova, Maia, Lyra, Mira, Luma, Rhea, Sera. Стиль визначає класи компонентів (висоти, радіуси, відступи, типографіку), а не кольори — кольори дають наші теми. Хвиля 0, крок 0.2: порівняти 2–3 стилі на сторінці-зразку й обрати один.

До порівняння взято стилі, сумісні зі SPEC §6.5 (радіус 8 px, спокійна оболонка, база 14 px):

| Стиль | Кнопка/поле | Радіус кнопки | Текст | Примітка |
|---|---|---|---|---|
| Vega | 36 px | ~6 px (`rounded-md`) | 14 px | класичний shadcn |
| **Nova** | 32 px | **8 px** (`rounded-lg`) | 14 px | типовий для Base UI, шрифт Geist |
| Mira | 28 px | ~6 px | 12 px | найщільніший; менший за базу SPEC |

Відкинуто без порівняння: Maia, Luma (радіус ~21 px, «пігулки»), Rhea (~14 px), Lyra (без заокруглень, моноширинний), Sera (редакційний, uppercase).

Скриншоти: `docs/screenshots/wave-0/0.2/compare/` (кнопки й поля 1:1, Сапфір світла і Графіт темна, телефон 390 px).

## Рішення

Беремо **Nova**. Висоти в будь-якому разі задають токени щільності erp-ui (`--control-h`: 36 px звичайна, 32 px компактна), тож від стилю лишаються радіус, відступи й деталі.

Чому Nova:
- `rounded-lg` = `--radius` = 8 px — збігається зі SPEC без правок;
- Geist — шрифт стилю за замовчуванням, як у нас;
- типовий стиль shadcn для Base UI: блоки й реєстри (ReUI тощо) найчастіше орієнтуються на нього, тож при перебудові зовнішніх компонентів (ADR-0006) правок найменше.

## Наслідки

- Примітиви в `registry/ui/` взято з `base-nova` (shadcn 4.21.4) і перебудовано за ADR-0006: висоти з токенів, суцільне кільце фокуса, статусні варіанти бейджа, read-only, українські підписи за замовчуванням.
- Шкала радіусів — мультиплікативна, як у Nova (`rounded-md` = 0.8 × `--radius`, `rounded-xl` = 1.4 × …), у `registry/tokens/base.css`.
- Компоненти інших стилів (зокрема з ReUI) перед додаванням зводяться до класів Nova.
