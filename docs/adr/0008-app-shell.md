# 0008. Оболонка застосунку, палітра команд і словник іконок

- Статус: прийнято
- Дата: 13.10.2026
- Хто ухвалив: власник (вікторини 13.10.2026)

## Контекст

Крок 0.4 мав дати оболонку, однакову для всіх проектів:

- навігація для десктопа, планшета й телефона (SPEC §7);
- топбар із хлібними крихтами, пошуком і сповіщеннями;
- палітра Cmd/Ctrl+K (UI15);
- меню користувача з перемикачами вигляду й мови;
- перемикач компанії (PF02);
- стани сторінки (§8.1);
- словник іконок із власною ₴.

SPEC передбачав для палітри cmdk як виняток із бар'єра 2: останній реліз cmdk — березень 2025.

## Рішення

1. **Навігація — на shadcn Sidebar (Nova), перебудованому за ADR-0006** (`ui/sidebar`):
   - десктоп (≥ 1280 px) — розгорнутий сайдбар із групами; згорнутий стан пам'ятається в localStorage;
   - планшет (768–1279 px) — вузька панель з іконками й підказками;
   - телефон — нижня панель на 4 пункти (`mobile: true`) + «Ще», що відкриває повне меню в шторці;
   - пункти — `h-control`, але не нижче цілі дотику (44 px у звичайній щільності);
   - Ctrl+B не спрацьовує в полях вводу й редакторах, щоб не красти «жирний».
2. **`erp/app-shell`** складає це разом із топбаром і посиланням «Перейти до вмісту»:
   - посилання — `<a href>` або `renderLink` для роутера;
   - `html:has([data-slot=app-shell])` задає `scroll-padding`, тож липкі панелі не закривають елемент у фокусі (WCAG 2.4.11).
3. **Палітра команд — на Base UI Autocomplete** (`erp/command-palette`), за офіційним зразком Base UI; cmdk не беремо (рішення власника):
   - пошук за назвою й ключовими словами без урахування регістру й діакритики;
   - Enter виконує команду, Esc закриває;
   - Ctrl+K / ⌘K працює й у полях вводу.
4. **Меню користувача** (`erp/user-menu`): тема, палітра, щільність, мова й темний сайдбар.
   - Сховище вигляду переїхало з демо в кіт: `lib/appearance` + `hooks/use-appearance`;
   - `syncLanguage` пов'язує його з i18next;
   - перемикачі не закривають меню — результат видно одразу.
5. **Перемикач компанії** (`erp/company-switcher`) — у шапці сайдбара; у вузькій панелі лишається квадрат з ініціалом.
6. **Сповіщення** (`erp/notification-bell`) — заглушка з лічильником у підписі кнопки до PF10.
7. **Стани сторінки** (`erp/page-state`):
   - `PageState` — порожньо вперше, нічого не знайдено, помилка з повтором, немає доступу, офлайн, не знайдено;
   - `PageSkeleton` — первинне завантаження;
   - тексти — з рядків кіта;
   - помилка й офлайн оголошуються як `role="alert"`.
8. **Словник іконок** (`lib/icons`):
   - поняття → іконка lucide: 104 модулі (A1…T1, LC01…LC12), статуси, дії з документами, оболонка;
   - назви модулів — у рядках кіта;
   - `HryvniaIcon` — ₴ у стилі lucide;
   - **товщина лінії — 2** (стандарт lucide, вибір власника за скриншотами), задається одним `IconProvider`.
9. **Нові примітиви** (ADR-0006):
   - перенесено: sidebar, dropdown-menu, avatar, breadcrumb, kbd, popover, empty, alert;
   - Alert отримав статусні варіанти (soft-тло + `*-foreground`);
   - dropdown-menu: деструктивний пункт — `destructive-soft`.

## Наслідки

- Нова залежність не додалась. Виняток для cmdk більше не потрібен; SPEC §4 оновлено.
- Сітки сторінок мають задавати `grid-cols-1` (`minmax(0, 1fr)`). Інакше таблиця з мінімальною шириною розпирає сторінку на телефоні. Перевірка «без горизонтальної прокрутки» є в e2e на 360/390/768.
- Перемикач мови з кроку 0.3 переїхав із шапки демо в меню користувача й палітру команд.

## Розглянуті варіанти

- cmdk як виняток — відхилено власником: Base UI дає те саме без нової залежності.
- Власний сайдбар замість shadcn — відхилено: shadcn уже має вузьку панель, шторку на телефоні й клавіатуру. Перебудувати дешевше, і так зберігаємо сумісність з оновленнями.
- Лінія 1,75 — відхилено власником після порівняння скриншотів.
